# Xuxuan Profile — 个人网站设计方案

**日期：** 2026-08-20
**状态：** 已确认

---

## 概述

杨许煊个人经历展示网站，分类整合高中及大学阶段的荣誉、奖项、经历等。
当前为框架阶段，使用占位内容搭建完整结构，后续逐步填充真实照片和文字。

---

## 技术方案

- 单 HTML 文件 + CSS + JS
- 零依赖，浏览器直接打开即可预览
- 部署到 GitHub Pages 或其他静态托管

---

## 设计风格

- 极简白底 + 线条感
- 学术克制风，理性干净
- 蓝/金色作为点缀强调色
- 系统默认无衬线字体

---

## 页面结构

```
封面页（滚动进入）
    ↓
首页（个人简介 + 高中/大学入口卡片）
   ↙        ↘
高中页          大学页
4 个板块       8 个板块
```

### 封面页
- 全屏居中，大标题"杨许煊的个人网站"
- 副标题（可选）
- 向下滚动提示（箭头动画）
- 滚动后封面淡出上移，首页从下方升起

### 顶部导航栏
- 固定顶部，白色背景 + 底部细线
- 左侧：名字/logo
- 右侧：首页 | 高中 | 大学
- 当前页有下划线标记，切换时平滑滑动

### 首页
- 居中大标题（名字）
- 简短自我介绍
- 两张卡片并排：高中入口、大学入口
- 背景极淡几何线条装饰

### 高中页
- 左侧板块导航：高考学习 | 学科竞赛 | 足球 | 校园生活
- 右侧内容区，点击切换，平滑过渡
- 占位内容：示例文字 + 占位图片

### 大学页
- 左侧板块导航：实习经历 | 科研/论文 | 学科成绩 | 足球 | 竞赛 | 志愿者 | 校园生活 | 英语
- 右侧内容区，点击切换，平滑过渡
- 占位内容：示例文字 + 占位图片

---

## 交互

- 封面→首页：滚动触发，封面淡出上移
- 页面切换：导航栏点击，内容区淡入淡出
- 板块切换：左侧导航点击，内容区平滑过渡
- 所有过渡动画：~300ms ease

---

## 占位内容规范

- 文字：使用"示例文字 / 待补充"等标记
- 图片：使用灰色占位方块，标注尺寸
- 后续替换时直接找到对应标记替换即可
